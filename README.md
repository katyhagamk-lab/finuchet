# Финучёт: подготовка к контрольной

Учебная платформа по курсу «Финансовый и управленческий учёт»: теория с мини-заданиями, разборы контрольной, варианты, банк заданий, схемы.

Сайт: https://katyhagamk-lab.github.io/finuchet/

Сборка: `cd src && node build.mjs` собирает `index.html`, `node test.mjs` проверяет расчёты.
Облачное сохранение прогресса: Supabase, схема базы в `supabase.sql`, настройки в `src/config.js`.
